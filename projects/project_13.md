### Background
&nbsp;&nbsp;&nbsp;&nbsp;This was a history education platform project selected through a government-funded program. We were commissioned to develop a platform connecting history education program providers with users.

### Team Size
- Project Manager: 1
- Designer: 1
- Backend Developer: 1
- Frontend Developers: 2

### Responsibilities
- Developed approximately 50% of the UI/UX for core feature implementation.
- Implemented location marker management and map interactions for history education programs using the Naver Map SDK (100%).

### Key Features
- A platform connecting history education program providers and users.
- Provides education-related mini-games and treasure hunt features to encourage user participation.
- Supports user-customized functions such as program information registration, location-based search, and participation history tracking.
