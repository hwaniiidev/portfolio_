### Team Size

### Responsibilities
- Maintain and develop the Android SDK (50%)
- Design and develop the Android SDK for location data collection (100%)
- Design and develop the Android SDK for vehicle boarding and alighting detection (100%)


### Key Features
- Recognizes user locations based on Wi-Fi and Bluetooth beacon data.
- Detects user activity and activity duration based on physical activity and location data.
- Sends notifications when users visit client-specified stores.
- Collects in-store information for clients (using a separate SDK from the location recognition SDK).
- Detects vehicle boarding and alighting using in-vehicle tablets and beacon data (using a separate SDK from the location recognition SD).
